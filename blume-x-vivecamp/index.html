Dos modos

Lo mismo, con o sin dormir

La carpa es la misma. Lo único que cambia es si la gente se queda.

Modo 1

Las carpas son el VIP

Nadie duerme. Las carpas rodean la pista como palcos de lona: mesa adentro, servicio y vista al escenario. Se montan y se quitan el mismo día.

  • Sin pernocta
  • Mesa con servicio
  • Se vende como VIP
Modo 2

El VIP se queda a dormir

Las mismas carpas, con colchonetas. El festival no se acaba a las dos: sigue con faroles, fogata y un set al amanecer.

  • Pernocta por confirmar
  • Dos días
  • Set al amanecer
Lo primero que hay que preguntar

Si el venue no permite dormir, el Modo 1 funciona solo y nada de esta propuesta se cae.
